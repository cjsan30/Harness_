## Findings Fixed During E2E

- The initial test incorrectly expected the `필터 초기화` button while search results still existed. The flow now clears the search input directly.
- The initial test treated `AI Analysis` as a heading, but the UI renders it as eyebrow text. The assertion now matches the actual UI semantics.
- `@playwright/test@1.53.0` triggered a high severity audit finding through `playwright <1.55.1`. It was upgraded to `@playwright/test@1.60.0`; `npm install` then reported `found 0 vulnerabilities`.
- Backend and frontend originally had to be started separately for manual checks. Added root `npm run dev` so both runtime servers start together, with port overrides through `BACKEND_PORT` and `FRONTEND_PORT`.
- Frontend server failures on occupied ports printed a raw Node stack trace. Added explicit port checks and concise conflict guidance.
- Playwright webServer commands used shell-specific environment assignment. They now use Playwright `env` fields so WSL and PowerShell runs use the same port/API variables.
